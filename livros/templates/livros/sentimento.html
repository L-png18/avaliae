  2. 2. Resultado do VADER

    O VADER dá uma pontuação neg, neu e pos (a proporção do texto em cada sentimento) e um compound, que resume tudo numa nota de -1 a +1. A classe sai do compound.

    {{ resultado.original.classe|capfirst }} {{ resultado.original.compound_texto }} compound
    -1 (negativo)0+1 (positivo)
    {% for barra in resultado.original.barras %}
    {{ barra.rotulo }}
    {{ barra.valor }}
    {% endfor %}

    Regra do slide: compound > 0,05 → positivo · compound < -0,05 → negativo · entre os dois → neutro.

  3. 3. Palavras que pesaram {{ resultado.palavras|length }}

    O VADER tem um léxico com a intensidade de cada palavra (de -4 a +4). Ele também ajusta a nota quando encontra negações e intensificadores.

    {% for p in resultado.palavras %}{{ p.palavra }}{% if p.valor %}{{ p.valor }}{% endif %}{% empty %}Nenhuma palavra do léxico foi encontrada neste texto.{% endfor %}

    Verde: positiva · Vermelho: negativa · Tracejado laranja: negação · Tracejado: intensificador (very, extremely…).

  4. 4. E se o texto for pré-processado antes?

    O VADER usa pontuação (!!!), MAIÚSCULAS, emoticons (:() e a posição das negações para ajustar a nota. O pré-processamento da etapa 2 apaga ou muda parte disso (e pode trocar uma palavra do léxico pelo seu lema). Compare:
